### What I learned
- reduce() uses an accumulator to combine array elements into a single result, and the initial accumulator value depends on the operation being performed.
- find() returns the first matching element or undefined if no match exists.
- some() returns true if at least one element satisfies a condition, while every() returns true only if all elements satisfy it.
- Learned that every() returns true for an empty array because there are no elements that violate the condition.
- Learned how to combine filter() and reduce() to calculate values from specific elements in an array.
- Learned how to use assert.equal() to automatically verify expected outputs instead of manually checking console.log().
- Learned that structuredClone() creates an independent copy of supported data and assert.deepStrictEqual() compares the contents of objects and arrays.
- Learned the importance of testing both a function's returned values and whether it accidentally modifies the original data.
