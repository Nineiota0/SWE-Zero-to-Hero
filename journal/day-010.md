### What I learned
- A Set stores unique values and automatically ignores duplicates.
- A Map stores key-value pairs and allows keys of different data types, including objects.
- Set and Map use .size instead of .length.
- .add() returns the Set itself, while .delete() returns a boolean indicating whether an element was removed.
- .set() can create a new Map entry or update an existing entry.
- JavaScript Maps preserve insertion order when iterating through entries.
- Objects used as Map keys are compared by identity, not by their property values.
- for...of can be combined with destructuring to access Map keys and values.
- Learned how to implement a counting system using a Map by initializing new usernames with a count of 1 and incrementing existing counts.
- Learned how to verify that functions do not mutate arrays or Maps using snapshots and automated assertions.
- Learned how intentionally introducing a bug can help me practice reading assertion errors and identifying incorrect behavior.
