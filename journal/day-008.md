### What I learned

- .map() transforms each element and returns a new array containing the callback's returned values.
- .filter() creates a new array containing only elements whose callback results are truthy.
- Both methods accept callback functions, connecting directly to what I learned about functions on Day 4.
- .map() can be combined with object spread to create updated objects without mutating the originals.
- .push() modifies an existing array and returns its new length, while .map() constructs a new array from callback return values.
- .filter() creates a new array but doesn't automatically copy the objects inside it.
- Testing should include normal inputs, empty arrays, all-matching cases, none-matching cases, and checks for unintended mutation.
- Learned about console.assert() as an introduction to automated testing.
