### Mistakes / Bugs

Mistake 1) Initially I used "switch(true)" instead of directly on the value I wanted to compare. I learned that the normal switch model is switch(value) with each case representing a candidate value.

Mistake 2) I used switch(true) with string cases like "Monday" which would not match so I corrected it to switch(dayName) so that JS compares the day directly against each case

Bug/Mistake 3) In canLogin() I assumed username && password && isActive would always return true or false. I discovered that JS's && operator can return the actual operand rather than a boolean. This caused failed login cases with an empty username/password to return "", which appeared as blank lines when printed. adhering to truthy falsy rules.
