### What I learned

- I learned how objects allow related information to be grouped together instead of storing everything in separate variables. I also learned about how dot notation can access a property by its literal name, while bracket notation can evaluate a variable to determine which property to access. I also learned that functions can accept objects as arguments and access or modify their properties. When an object is passed into a function, both the caller and the function can refer to the same underlying object. I learned that mutating an object's properties is different from reassigning a local parameter to a different object.
