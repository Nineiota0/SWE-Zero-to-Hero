### What I learned
- After today's lessons and exercises, I learned about JavaScript's variable typing. I learned the difference between const and let. Const prevents the reassignment of the variable binding while lets does allow for reassignment. This typing differs from C++ as in C++, variable type declaration happens before runtime, while in JS, values have types and a variable can refer to values of different types during runtime.

I also learned about JS's int equavalent which is called number instead of int, double, long long in C++. JS also has an undefined type which is produced if a variable has no real assigned type. The typeof function also allows console.log() (JS's print statement) to print the type of the variable. There is also a thing called type coercion where when adding a number and a string like 5 and "5" it produces "55" which when used with typeof produces a string. On the other hand subtracting a number and string produces a number so 5 - "5" gives us the number 0. Something interesting I learned today was the loose equality "==" and strict equality "===" operators. == gives us equality without taking into consideration the typing of the variables so 5 and "5" would gives us true. === on the other hand gives us a strict equality based on their typing so 5 and "5" gives us false.
