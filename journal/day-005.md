### Mistakes / Bugs

Mistake 1) Using .length() as a method while .length is the correct syntax. This is because length is a property not a method function. When you add () to something in JS, you are telling the program to execute the function.
ex - arr.length() -> C++ != arr.length -> JS

Mistake 2) Incorrectly accessing last element in array. To access the last element in the array it is arr[arr.length - 1], while in C++ it is arr[arr.size() - 1]; In C++ we can also use the .back() method so arr.back();

Mistake 3) Incorrectly setting i pointer to last element in array. I got mixed up and used 
arr[arr.length - 1] (used to access last element) instead of arr.length - 1 (get size of array)
