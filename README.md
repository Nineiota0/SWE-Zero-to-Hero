## AI Usage

**During this rebuild:**

1. I attempt problems myself before asking AI.
2. I can ask AI for explanations and documentation.
3. If I'm stuck, I ask for a hint before asking for code.
4. I don't submit AI-generated code that I can't explain.
5. If AI shows me a solution, I try to reproduce it afterward without looking.
6. I regularly build things without AI assistance.
7. I use AI primarily as a tutor and reviewer rather than as the person doing the work.

## How I'll Track AI Assistance

🟢 Independent — completed without AI assistance

🟡 Assisted — AI gave explanations or hints, but I wrote the solution

🔴 Solution — AI provided substantial code or the solution

My goal is not to eliminate AI, but to ensure that I can understand, produce, debug and explain the software I create on my own.
